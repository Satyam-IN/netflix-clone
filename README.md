# Netflix Clone

A responsive Netflix landing page clone built using HTML and CSS. This project recreates the Netflix homepage layout and includes responsive design for different screen sizes.

## Features

- Netflix-inspired user interface
- Responsive layout for desktop, tablet and mobile
- Trending movies section with horizontal scrolling
- Interactive hover effects
- Email input section
- FAQ section
- Custom CSS gradients and styling

## Technologies Used

- HTML5
- CSS3
- CSS Flexbox
- CSS Grid
- CSS Media Queries

## Installation

1. Clone the repository:

   `git clone https://github.com/Satyam-IN/netflix-clone.git`

2. Open the project folder.

3. Open `index.html` in your browser or use the VS Code Live Server extension.
